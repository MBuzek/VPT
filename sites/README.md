# VPT Sites — The Nine-Site Hub Model

VPT's SharePoint is organized as a **hub** with nine connected sites. Each site
maps to a business function. Content lives under a site by *what it is*, not
*whose it is*.

Each folder below contains a `README.md` describing that site's **purpose**,
**access tier**, **sub-headings**, and **what belongs / what doesn't**.

| # | Site | Access | Notes |
|---|------|--------|-------|
| 1 | [Management](1_Management/) | **Restricted** | Owners + Site Managers only |
| 2 | [Finance](2_Finance/) | Departmental + view | Sub-headings defined |
| 3 | [Compliance](3_Compliance/) | Departmental + view | Sub-headings PENDING |
| 4 | [HR](4_HR/) | **Restricted** | Owners + HR only |
| 5 | [Funding](5_Funding/) | Departmental + view | Sub-headings PENDING |
| 6 | [Title Operations](6_Title_Operations/) | Departmental + view | Sub-headings PENDING |
| 7 | [IT](7_IT/) | Departmental + view | Incl. Password Manager (governance) |
| 8 | [Legacy / Archive](8_Legacy_Archive/) | Upper tier + dept heads | Archived, not deleted |
| 9 | [All Company](9_All_Company/) | All staff (view) | Company-wide shared content |

## Sub-heading status

Concrete sub-heading trees are defined for **Finance** and **IT** (from the
planning docs). The remaining sites carry a **recommended starting structure**
marked **PENDING manager input** — a known open item to resolve with Dan, Brandy,

## Migration note

Source folders from the current environment map into these sites and
sub-headings (e.g., `Accounting/Audits` → `Finance / Audits & CPA`). Migration
does **not** begin until the [access model](../governance/ACCESS_MODEL.md) is
signed off by leadership.
