# Title Operations

**Purpose:** The core title production workflow — commitments, title work,
closings, and settlement documents.

**Access:** Departmental contribute (Title Ops staff) + view-only for other
non-restricted tiers per the access model.

## Sub-headings — PENDING manager input

Recommended starting structure (confirm before migration):

- **Title Commitments**
- **Closings & Settlements**
- **Recorded Documents**
- **Templates & Forms**

## Naming note

Title/closing files are often per-transaction. Use the transaction party as the
**Entity** so files group and sort naturally:

```
SmithEstate_Title_2024-05_Commitment_v1.pdf
SmithEstate_Closing_2024-05-15.pdf
```

## What belongs here

- Title commitments, closing/settlement packages, recorded docs
- Reusable templates and forms

## What does NOT belong here

- Funding/disbursement records → Funding
- Closed transactions past retention → Legacy / Archive
